# Compliance Policy

The reference deployment is designed to support SOC 2 Type II evidence collection by recording traceable audit events, usage metrics, source citations, and reviewer handoff notes. Actual SOC 2 reports must be supplied by the operating company.

GDPR support requires a documented subprocessors list, data processing agreement, retention policy, and deletion workflow. The copilot should not store unnecessary personal data in prompts, logs, vector metadata, or evaluation datasets.

For regulated deployments, the system owner should document model provider choices, data residency controls, access reviews, retention windows, and human approval requirements.
