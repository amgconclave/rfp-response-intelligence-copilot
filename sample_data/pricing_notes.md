# Pricing and Packaging Notes

The portfolio reference implementation includes three fake commercial tiers for demonstration only.

Pilot tier: fixed 30-day implementation package for sample documents, local deployment, retrieval evaluation, and stakeholder review.

Team tier: subscription for one sales engineering team, including document ingestion, cited RFP answers, response drafting, audit logs, and monthly evaluation reporting.

Enterprise tier: custom deployment for multiple business units with optional Azure OpenAI, Azure AI Search, enterprise identity, document repository integrations, and stricter data residency controls.

Usage-based AI cost assumptions should separate input tokens, output tokens, retrieval infrastructure, document parsing, and reviewer workflow costs.
